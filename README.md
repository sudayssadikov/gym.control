# APEX FITNESS CLUB — Premium Fitness Complex Web Application

Toshkentdagi zamonaviy premium fitnes va sog'lomlashtirish majmuasi uchun yaratilgan to'liq React veb-ilovasi.

## 🚀 Texnologiyalar
- **React 18** (Sof JSX & JS)
- **Vite** (Tezkor yig'ish va dev-server)
- **Zustand** (Holatni boshqarish va LocalStorage persist)
- **React Router DOM** (Marshrutlash)
- **Lucide React** (Zamonaviy vektor ikonlar)
- **Recharts** (Vazn va parametrlar dinamikasi grafikasi)
- **Vanilla CSS / CSS Tokens** (Glassmorphism, dark/light tema, 8px grid)

## 📌 Asosiy Imkoniyatlar
1. **Asosiy Sahifa**:
   - High-impact dizayn, zal statistikasi va Technogym uskunalari haqida ma'lumot
   - Mashg'ulot zonalari (Zal, Kardio, Krossfit, Yoga, Boks, Sauna)
   - Bugungi darslar va eng sara xalqaro chempion murabbiylar
   - Mijozlar fikrlari va tez-tez beriladigan savollar (FAQ accordion)
2. **Guruh Mashg'ulotlari Jadvali**:
   - Hafta kunlari va toifalar bo'yicha saralash
   - Dars sig'imi va bo'sh o'rinlar ko'rsatkichi
   - Bir bosish bilan band qilish (BookClassModal)
3. **A'zolik Tariflari**:
   - START, PRO FIT, VIP ELITE BLACK paketlari
   - 1 oylik, 3 oylik (-15%), 1 yillik (-25%) to'lov davri almashinuvi
   - O'zbekiston to'lov tizimlari (Payme, Click, Uzum Bank, Karta) orqali onlayn faollashtirish
4. **Professional Murabbiylar**:
   - Shaxsiy murabbiylar ma'lumotlari, sertifikatlari va yutuqlari
   - Shaxsiy mashg'ulot so'rovi yuborish
5. **Shaxsiy A'zo Kabineti**:
   - Virtual Raqamli Club Pass (QR-kodli kartochka)
   - Obunani bepul muzlatish (Freeze) va qayta faollashtirish
   - Yozilgan darslar tarixi va bekor qilish
   - Vazn o'zgarish dinamikasi (Recharts interaktiv grafikasi)
   - Mashg'ulotlar kundaligi va to'lov kvitansiyalari
6. **Administrator Paneli**:
   - Statistika, yangi guruh darslarini jadvalga qo'shish, a'zolarni nazorat qilish
7. **Demo Profil Almashgich (Role Switcher)**:
   - Saytni Faol PRO a'zo, Yangi a'zo, Muzlatilgan a'zo, Admin yoki Mehmon sifatida bir zumda sinash.

## 🛠 O'rnatish va Ishga tushirish

```bash
# Kutubxonalarni o'rnatish
npm install

# Dasturchi rejimida ishga tushirish
npm run dev

# Ishlab chiqarish uchun yig'ish (Production build)
npm run build
```
